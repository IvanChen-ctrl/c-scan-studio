# C-Scan Studio v3.6.0-beta.4 压力回归记录

## 测试方式

采用 GitHub Actions Windows + Ubuntu 双平台、Python 标准库隔离测试。预览压力用内存合成的 `Snapshot`，不创建真实 C 盘缓存；目录竞态用系统临时目录（自动回收），不访问用户磁盘。清理 API 的正向测试会模拟线程启动，并非真实删除。

## RED 基线：beta.3 实际失败（CI 41250442883）

| 场景 | 测试规模 | 旧版实际结果 |
| --- | --- | --- |
| 预览分页 | 80,000 文件、320 页 | FAIL：重复遍历 25,600,000 条记录 |
| 并发预览 | 25,000 文件、16 线程、400 页 | FAIL：重复遍历 10,000,000 条记录 |
| 同数量路径替换后翻页 | 更换 1 条记录、总数不变 | FAIL：旧票据仍返回数据 |
| 同数量路径替换后执行清理 | 更换 1 条记录、总数不变 | FAIL：接受旧票据发起清理 |
| 排队目录替换为 symlink | root 扫描后替换其下级目录 | FAIL：跨过 symlink 读取外部文件 |

另外的模拟目录失联以及正常一次性清理测试通过。

## 修复后的 GREEN 验收标准

- 预览分页从每页复制所有快照变成先冻结一次后按页读取，320 页的源列表遍历应低于或等于 160,000 条；并发 400 页低于或等于 50,000 条。
- 在分页范围内发现任何与冻结票据不同的记录，应撤销凭证并返回错误；执行 DELETE 前重新全量比较已冻结的每条记录。
- 显式拒绝已排队路径后来变成符号链接/重解析点或不同目录的情况；失联/权限错误必须计入不完整，不得报告全盘完整。
- 所有历史 Python/JS 回归、CodeQL、Windows/Linux 发行包 SHA-256 相等和发布前二次回归必须通过。

## 已知未覆盖范围

Windows 上极短的 `lstat` 与 `scandir` 调用之间仍存在 TOCTOU 竞态窗口。真正抗恶意并发路径替换需基于平台句柄的不可重解析目录遍历，当前不能声称对该攻击完全免疫。还需独立设备测试：NTFS/ReFS、FAT/exFAT、真实 USB 掉线、低内存/低电量和多小时重复扫描。以上不构成病毒检测认证，也未执行真实文件删除。
