# C-Scan Studio v3.5.2-beta.1 · Ergonomic Hierarchy Preview

> 本版为独立预发布版本。**不会覆盖 v3.3.1 稳定版或 v3.5.0-beta.1。** 新版本需新的 Windows 实机验收和独立 VirusTotal 报告；旧版病毒检测结论不能移植。

## 1. 人体工学界面改版

- 主界面保留四层优先级驾驶舱：绿色优先评估、黄色人工确认、橙色只读复核、红/灰保护。
- 根据用户进入的页面切换标题和工作上下文；工作页面不重复展示整页首页指标，减少滚动距离。
- 移动端菜单从“仅图标”改为可阅读的图标+名称；扩大焦点区域和按键触达面积，保留键盘焦点样式。
- 用户设置“减少动态效果”时，减少动画，提升可访问性。

## 2. 真正可展开的建议树

- **目标 → 阶段 → 具体建议**，提供三个可切换目标：C 盘空间不足、整理其他磁盘、核验安全来源。
- 每个阶段显示当前状态、风险颜色、需人工确认程度，以及转至对应功能页的入口。
- 为了防止轮询刷新时丢失状态，建议树只在扫描数据或目标变化后重新绘制。
- 绿色仅表示建议优先评估，**不代表系统会自动执行删除**。

## 3. 其他盘“多级分类树”

- **大类族群 → 文件类别 → 基于扩展名的子类 → 已选择磁盘 → 文件清单**。
- 示例：`影像与创意素材 → 图片/设计素材 → 相机原始格式 → E: → 已扫描文件`。
- 每个节点汇总已扫描文件数和逻辑大小，不在聚合树中发送完整个人路径。
- 点击末级节点，继续通过本地带令牌的、最多 100 文件/次的只读分页接口查看文件路径。
- 子类 ID 和磁盘过滤值必须存在于服务器本次扫描的层级快照；不接受任意磁盘路径/UNC/遍历参数。
- 分类仅基于扩展名和文件名，**不是 AI 内容理解**；不推断文件内容是否值得删除。

## 4. 安全边界与已知限制

- 新分类模块不包含删除、移动、重命名、隔离或上传接口。
- C 盘清理仍默认不选择，且必须逐文件预览、使用单次授权并输入 `DELETE`。
- 磁盘扫描与哈希仍按预算限制，超限/无权限/中断时明确为不完整。
- 所有“可回收”空间是逻辑大小估算，不能保证相同量的净空闲空间变化。
- 本轮仅进行跨平台隔离测试和模拟浏览器交互，**尚未在真实 Windows 非系统磁盘完成长时间扫描及清理验证**。
