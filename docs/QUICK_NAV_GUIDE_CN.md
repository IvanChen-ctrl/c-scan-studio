# C-Scan Studio v3.6.0-beta.2 快捷操作

打开唯一 BAT 后，使用 Ctrl+K（或非输入框时 /）查找界面模块，回车跳转，Esc 关闭；此行为不会扫描或删除。
在智能缓存清理页，手动选择候选项并查看绿色/黄色风险和逻辑大小。点击“清空选择 · 不删除”只撤销勾选。
要真正清理，仍需读取逐文件预览并输入 DELETE。如果显示本地连接中断，请取消原预览后重新进行操作。
多盘查重与分类始终只读。

### 回归修复说明
如果网络在清理请求已发送后中断，看到“执行结果未能确认”时不要马上重新点清理：查看本地日志和磁盘剩余空间再判断。多次点击预览会自动防重入；更换选择后旧的预览会失效，必须重新进行逐文件确认。
