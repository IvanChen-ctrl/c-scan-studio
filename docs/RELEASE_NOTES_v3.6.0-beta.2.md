# v3.6.0-beta.2 · 安全快捷导航与清理候选复核

- Ctrl+K、非输入框下 / 或按钮打开命令导航，只跳转模块，不执行任何系统命令。
- 选择核对条显示绿色/黄色缓存项数及逻辑大小；黄色提醒文件重建风险；一键清空只撤销勾选。
- 本地连接失联时禁用清理确认，后台白名单、逐文件预览、单次票据和 DELETE 不变。
- 多盘 SHA-256 查重和智能分类仍只读，不提供删除/移动/重命名权限。
- 新增 tests_v362，要求 Windows/Linux CI 与 CodeQL 通过才能发布独立源码 ZIP 和校验文件。
- 真实 Windows 删除、多盘性能及 VirusTotal 独立样本检测尚未执行；已有截图只代表 beta.1。

## 回归驱动修复（本次补充）

- **失联后结果未知**：如果删除请求发出后 HTTP 响应丢失，界面不再宣称“未执行清理”；明确要求查看日志、检查磁盘且不要立即重试。
- **双击/重入保护**：预览请求和 DELETE 提交各自使用单飞锁，避免两次并发请求使授权状态混乱。
- **选择快照失效**：预览请求飞行期间修改选择会作废先前结果并撤销服务端票据；自动淘汰已不允许的项目也会令预览失效。
- **断线和到期保护**：预览列表读取时断线不能重新启用 DELETE；票据剩余时间为 0 时强制禁止确认；断线后即使恢复也必须取消旧预览重新生成。
- **实际交互验证**：`tests_v362/browser_behavior.cjs` 通过 Node.js 内建 VM 运行真实 dashboard 脚本，mock 本地请求，验证快捷导航、风险计数、重复请求、选项变更、过期、断线、结果未知以及重复确认；不会访问真实磁盘。

> CI 与 CodeQL 结果以 GitHub Actions 对应提交为准。以上为模拟浏览器逻辑回归，并非真实 Windows 文件删除或安全认证。
