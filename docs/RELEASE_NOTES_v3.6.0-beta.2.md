# v3.6.0-beta.2 · 安全快捷导航与清理候选复核

- Ctrl+K、非输入框下 / 或按钮打开命令导航，只跳转模块，不执行任何系统命令。
- 选择核对条显示绿色/黄色缓存项数及逻辑大小；黄色提醒文件重建风险；一键清空只撤销勾选。
- 本地连接失联时禁用清理确认，后台白名单、逐文件预览、单次票据和 DELETE 不变。
- 多盘 SHA-256 查重和智能分类仍只读，不提供删除/移动/重命名权限。
- 新增 tests_v362，要求 Windows/Linux CI 与 CodeQL 通过才能发布独立源码 ZIP 和校验文件。
- 真实 Windows 删除、多盘性能及 VirusTotal 独立样本检测尚未执行；已有截图只代表 beta.1。
