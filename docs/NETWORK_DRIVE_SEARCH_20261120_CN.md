# v3.7.0-beta.1 Everything 搜索回归：映射网络盘 O: 等恢复（2026-11-20）

本变更从待合并 PR #13 的 `bae45e9488c8` 派生。它只改动只读大文件搜索、网盘识别、界面与测试；**不会更改已存在的 C 盘/Unity 清理授权、自动修改映射、网络凭据或连接设置**。

## 修复原因
旧 `Drive_Inspector.available_drives()` 仅显示 Windows DRIVE_REMOVABLE=2 与 DRIVE_FIXED=3，刻意排除了 DRIVE_REMOTE=4，导致映射到 O:、P: 等的企业共享盘无法选择。原有“其他盘分类/查重”仍仅允许本地盘，防止远程批量哈希产生网络负载。

## 新行为
* “大文件快速搜索”增加盘符选择器；默认为 C:，只额外列出当前 Windows 会话识别的 DRIVE_REMOTE 盘符 D: 至 Z:。
* 使用 `GetLogicalDrives` 和 `GetDriveTypeW` 只读枚举映射盘；真正启动搜索前重新确认盘符类型。不接受 UNC、任意文件夹或 C: 下的非系统范围。
* 先使用已经验证官方 SHA-256 的 Everything/ES CLI 查询所选网络盘；客户端严格校验结果必须属于该盘，且为可读取的普通文件。最多显示 180 项。
* 对未纳入索引的 O:，明确提示 Everything 1.4 的 `Tools → Options → Folders` 中手工添加 `O:\`，不假装“网盘没有文件”。
* 仅用户额外勾选并确认后才尝试网络盘限额扫描：最多 12 秒或 12,000 条目录项；可能因单个网络 I/O 阻塞而超过预期时间，不保证强制中断。
* 网络共享仅只读列文件名/大小/路径，不做完整网络查重或自动清理。网络结果可能包含公司内部路径，不自动上传。

## 回归检查
* 新增 `tests_v37/test_network_drive_search.py`：盘符白名单与拒绝 UNC、O: 与本地目录隔离、索引空结果绝不默认遍历、确认后的限额、非法参数拒绝、原本地多盘查重继续不接受网络盘。
* 原 Everything 搜索回归在 `tests_v37/test_everything_search_regression.py`；旧测试更新临界值 `>=` 断言。
* 需要 Windows/Linux GitHub CI、Windows EXE 冒烟、CodeQL、真实 O: 用户权限联调。当前没有任何实际公司 O: 共享盘的挂载或实盘测试结果，不应称为已完成 Windows 实机验收。

**注意**：Windows 管理员提升运行时，映射盘符可能不在相同登录会话中可见。应使用原本连接 O: 的普通用户会话启动 C-Scan。NAS/OneDrive 同步文件夹和 WebDAV 并非都被识别为 DRIVE_REMOTE；仅识别 Windows 映射的网络驱动器。

## 2026-11-20 网盘大小限制回归修正

- O: 等已映射网盘属于文件搜索，不采用 C: 的 128 MiB 起步门槛。网络盘永远使用 0 字节下限，包含 0 字节文件；UI 自动隐藏「最小文件」，C: 继续保留原来的容量筛选。
- 网盘可选输入普通「文件名关键词」（Unicode、空格、扩展名片段均支持），由 ES 索引在最多 180 条结果之前过滤，而不是只对首页结果做本地筛选。关键词使用正则转义并再次检查真实文件名，只读取文件元数据。
- 不填写关键词时，索引最多显示按文件大小排序的 180 项；**没有最小大小限制不等于索引返回整个网络盘**。远程只读递归仍必须用户明确勾选，有 12 秒/12,000 条目录项限制，但单次阻塞网络 I/O 可能超出这个时间。
- 追加针对 0 字节、1 字节和小文件、无效关键词、网络盘 UI、保留 C: 限制的回归测试。

## 2026-11-20 历史模块回归：网络盘索引计数诊断

- 历史 v3.3.1 已经包含 Everything/ES 查询及限额扫描，但只能搜索 C:。当时可以发现并执行 PATH 等位置的外部 es.exe。v3.4 起收紧为只执行经过本工具固定官方归档 SHA-256 验证的 ES；**不恢复对未知第三方程序的自动执行**。
- v3.7 PR #14 的 O: 文件名查询结果为空时，不能把“关键词未匹配”误报为“索引未就绪”。本分支使用原有已核验 ES CLI 做只读 -get-result-count 计数；如 O: 有已索引文件，再统计文件名关键词匹配数。没有打开共享文件内容、改变 Everything 设置或静默遍历共享目录。
- 索引状态代码：no_keyword_match=索引有条目但关键词无匹配；empty_or_missing=对映射盘符返回 0 个索引条目（可能未索引、尚在建立、UNC 路径不一致或确实为空）；matches_unreadable=索引有匹配但文件无法在本进程核验；entries_unreadable=索引有条目但无法显示；unknown/unknown_match=计数失败；verified_cli_missing=没有可信 ES；query_failed=ES 搜索失败。
- Everything 1.4 在 Tools > Options > Folders 手动加入 O:\；Everything 1.5 可从 Options > Network Drives 勾选 Include in database。管理员提升的会话可能看不到普通用户所映射的 O:。
- 若 Everything 是以 UNC 路径索引同一共享目录，当前 O: 盘符搜索不能假设其已经映射为 O:\ 索引。不能仅凭“0 条目”判断共享盘实际为空。
- 新增模拟 IPC/关键词/零索引/权限异常回归测试，需由 GitHub CI 实际验证。**尚未实机连接 O:，未实际建立网络盘索引，也未对网盘执行任何删除**。
