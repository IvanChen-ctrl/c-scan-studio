# 树状建议与分级分类：简明操作手册

## 首页：先看四层行动建议

绿色是低风险优先检查，不代表可无条件删除；黄色请逐项核对用途；橙色仅供只读复核；红色/灰色需要保护或使用原软件管理。所有 C 盘真实删除仍需预览并输入 `DELETE`。

## 分级建议中心

1. 点击左侧“分级建议中心”。
2. 在“我的目标”中选择 **C 盘空间不足 / 整理其他盘文件 / 提升安全与可信度**。
3. 点击第一层目标，再依次展开“阶段 → 具体建议”。
4. 使用每条建议后的“查看”，进入对应功能页面；跳转本身不会执行清理。
5. 如果缺少扫描数据，先完成相应的只读扫描。

## 其他盘：按层级分类

1. 选择 D:～Z: 中需要检查的本地固定磁盘或移动磁盘。默认不勾选任何磁盘。
2. 点击“开始只读分析”；可随时停止，未完成时报告将明确标注。
3. 在“树状文件分类”中逐层展开 **文件族群 → 文件类别 → 文件子类 → 盘符**。
4. 点击“查看本盘文件”，在下方通过每页 50 条的清单查看文件路径、大小、日期和分类依据。
5. 需要全部结果时，使用本地 JSON/CSV 导出；报告可能含完整个人文件路径，请勿公开发布。

**注意：** 此页面只提供信息和人工复核建议，不具备任何跨盘删除/移动操作。
