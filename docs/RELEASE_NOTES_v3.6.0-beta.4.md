# C-Scan Studio v3.6.0-beta.4 — 清理预览快照与目录竞态压力加固

此 Beta 独立发布，不覆盖 v3.6.0-beta.3 或稳定发行版。

## 核心修复

1. 清理预览绑定到整份不可变的候选文件快照（路径、大小、mtime），而不只是类别 ID 与文件总数。预览分页只借用当前快照作校验，显示原始冻结记录，避免每翻页就复制数万文件。
2. 删除请求的 **DELETE** 确认依然必须匹配单次预览凭证；现在还逐项比较完整快照。即使扫描项目总数不变，某个文件记录被替换也会拒绝清理并撤销授权。
3. 只读目录扫描在使用已排队路径前，重新检查目录类型、重解析点状态、设备号以及可用的文件索引，拒绝明显被替换的路径；目录丢失记为部分扫描。极短的检查与打开之间竞态仍需实际 Windows 文件句柄级验证。
4. 不改变多盘重复文件只读限制、SHA-256 全文哈希、缓存清理服务器白名单、单次预览票据或逐文件删除前校验。

## 回归矩阵

- 80,000 条合成候选 + 320 次预览分页；旧实现重复访问 **25,600,000** 条记录。
- 25,000 条合成候选 + 16 个并发读取线程、400 次分页；旧实现重复访问 **10,000,000** 条记录。
- 同总数文件替换后不得列出新路径或允许使用旧票据删除。
- 真实临时目录中，将已排队文件夹换成符号链接；不能沿旧路径读取目标数据。
- 临时测试目录模拟 USB 断连/目录不可读取；必须标记为扫描不完整。
- 未修改的票据仍只允许消费一次，原有用户交互回归继续执行。

## 构建与发布

Windows/Ubuntu 全部 Python 回归、Node.js 浏览器行为回归、构建前只读文件清单校验、跨系统 ZIP SHA-256 相等和 CodeQL 对**同一主分支提交**通过后，才发布独立 `v3.6.0-beta.4` Release（含源码 ZIP、SHA-256 和 GitHub 构建证明）。

**限制**：测试使用隔离临时目录/内存数据，不等于真实 120,000 文件的机械磁盘性能、实机 USB 热拔插、全部 NTFS 重解析点竞态或 Windows 删除验收；未申请独立 VirusTotal 报告。

5. **长时间多盘分析现在允许取消**：`Analyzer.stop()` 正确接受 `inventory` 阶段，使用既有取消事件停止只读扫描。新增后台线程级模拟回归，确保取消能使扫描工作线程退出，不使用真实磁盘。
