# C-Scan Studio v3.5.1-beta.1

本次迭代重点增强了界面的“结构感”和“人体工学导向”，让用户更容易按步骤理解：

1. **新增分级建议驾驶舱**
   - 顶部加入四层行动卡片：立即执行、人工确认、只读复核、保护与验证。
   - 扫描后可直接看到下一步路线，而不是先在多个页面之间自己推断。

2. **新增分级建议中心**
   - 原“高风险保护清单”扩展为分层建议页。
   - 建议不再是单一列表，而是按动作责任拆分为：
     - 第 1 层：立即执行
     - 第 2 层：人工确认
     - 第 3 层：只读复核
     - 第 4 层：受保护区域

3. **侧边导航重新分组**
   - 分为“分析与清理 / 建议与保护 / 透明说明”。
   - 帮助新用户快速建立心智模型。

4. **信息组织优化**
   - 主页改为“驾驶舱式”结构，统一承接扫描、建议、复核和保护规则。
   - 提高从扫描到决策的可读性，减少长表格造成的认知负担。

5. **保持原有安全边界**
   - 默认不勾选、不自动删除。
   - 其他盘查重与分类仍然是只读。
   - 高风险内容仍不开放 GUI 自动清理。
