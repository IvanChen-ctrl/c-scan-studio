# C-Scan Studio v3.5.0-beta.1 — 多磁盘查重与智能文件分类

此版本为**独立预发布测试版**。已发布的 v3.3.1 稳定版和 v3.4.0-beta.2 预发布版保持不变；此前 VirusTotal 报告不能用于本 ZIP。

## 新增功能

- 增加侧边栏 **「其他盘查重与分类」**：只能主动勾选 Windows 的 D:～Z: 本机固定/移动磁盘，默认全不选；明确拒绝 C:、网络盘、任意路径和重复盘符。
- 使用 `os.scandir` 本地只读扫描所选盘符；禁止跟随符号链接、联接点/重解析点，并跳过系统目录、Python 环境、node_modules 等高风险树。
- 重复检测使用 **文件大小 → 首尾采样 → 全文件 SHA-256**，只有完整内容校验一致才计入重复组；硬链接不计作额外占用副本。
- 每组按备份/模型/源代码/数据库保护规则标出建议保留的候选原件；剩余位置全部标为**人工复核建议**，没有删除/隔离/移动 API。
- 按扩展名和文件名的可解释规则将文件分成图片、视频、音频、文档、压缩包、安装包、模型、虚拟磁盘、代码、数据库和其他；展示数量、大小、依据和分类置信度。**不是模型语义理解，也不读取个人数据上传云端。**
- 分类文件按页（每页 50 条，最多 100 条）从已扫描快照中查询，不能传入任意文件路径；JSON/CSV 报告包含全部已识别文件与 SHA-256 重复组（报告可能含私人目录路径）。
- 扫描有时间、文件数、哈希读取量和哈希耗时限额；未完成、文件变化、权限不足、已取消时明确告知不完整，不把未验证结果当成完整重复结论。
- **C 盘缓存扫描也改为手动点击启动**，避免初次使用时自动扫描 C 盘占用任务槽。

## 安全边界

这个功能**没有删除、重命名、移动、隔离按钮或后台操作**。所有“理论重复逻辑大小”并非实际可安全释放的空间；压缩、硬链接、备份版本和被软件引用的文件会影响结果。任何可能删除操作都需要用户在资源管理器外部自行核实并自行执行。

Windows 本地设备上还未验证真实多磁盘 USB/NTFS 索引和长时间重复文件哈希。首次建议选择小容量测试磁盘，始终保留备份。

- 旧版 155 项测试回归全部通过；增加 29 项查重/分类/授权测试。
- Node JavaScript 静态检查通过；桌面及 390px 宽屏使用**模拟数据**完成浏览器静态渲染验证。
- GitHub Windows/Linux CI、CodeQL、Artifact Attestation 需依据**此版本提交的实际工作流结果**独立核实。
- 首次发布新的 v3.5 ZIP 时，必须使用其**自身 SHA-256** 重新提交 VirusTotal；不能复用 v3.4 或 v3.3 的报告。
