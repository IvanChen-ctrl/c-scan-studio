适合发给朋友的 3 步验证方法

01 · 独立校验压缩包

在 Windows 使用 Get-FileHash，对照发布者从另一个渠道提供的整包 SHA-256。

02 · Microsoft Defender

从“工具与高级维护”调用 Defender，或在资源管理器中右键扫描完整 ZIP。

03 · 公开检测结果

主动将发行 ZIP 上传以上服务，并把真实的报告 URL 分享给对方。每个新版本都要重新检测。

GitHub 开源发布与可信来源

公开源码、GitHub Actions 自动测试、CodeQL、安全问题报告与发行包构建来源证明可帮助朋友核验。只有发布成功并完成 Actions 检查后，才可以提供真实的 GitHub 绿色检查或构建证明链接。
