Use this folder if the PC is offline when no Python is installed.
1. On another computer, download the official Python 3.14.10 embeddable ZIP:
   64-bit Windows: https://www.python.org/ftp/python/3.14.10/python-3.14.10-embed-amd64.zip
   Windows ARM64:  https://www.python.org/ftp/python/3.14.10/python-3.14.10-embed-arm64.zip
   32-bit Windows: https://www.python.org/ftp/python/3.14.10/python-3.14.10-embed-win32.zip
2. Copy the UNMODIFIED ZIP into this folder, preserving the filename.
3. Double-click Run_One_Click.bat or Scan_Only.bat.
4. The launcher checks a PINNED SHA256 before extracting/running it.

NOTE: CPython ZIP binaries are NOT bundled with this kit. No Python is required to download them.
