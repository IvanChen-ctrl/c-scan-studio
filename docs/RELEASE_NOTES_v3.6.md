# v3.6.0-beta.1 · 单焦点人体工学 UI / Progressive Disclosure

这是一版**可运行的真实前端改造**，不是 AI 生成的概念图。主要修改集中在 `ui/dashboard.html`，没有扩大后端删除范围。

## 人体工学改进

- **一个主要行动**：首页优先展示「下一步做什么」，把次要建议放在短清单里，降低阅读负担。
- **更清楚的任务流程**：扫描 → 风险筛选 → 逐文件预览 → 确认执行；可折叠的安全原则不再占用整屏。
- **任务上下文**：面包屑显示所在模块；移动/桌面均有可识别的导航文字；切换页面自动回到顶部。
- **显示密度**：提供舒适/紧凑视图切换，不影响清理权限。
- **手机专用清理卡片**：展示风险、优先级、容量、路径、文件数、可选状态与详情操作；不再依赖横向滚动的 835px 宽清理表格。
- **多盘三段路径**：磁盘选择 → 分类统计 → 重复组复核，提供可操作的页内快捷导航。
- **可访问性**：显式焦点环、44px 左右操作目标、支持 prefers-reduced-motion；不再使用没有文字说明的纯图标手机导航。

## 保持的安全约束

- C 盘清理项目默认不勾选。即使是绿色缓存，也必须主动选择。
- 删除前仍要求服务端逐文件预览、限时单次确认凭证和 `DELETE`。
- 其他磁盘重复文件与分类模块只读，没有删除、移动或重命名能力。
- Everything 仅调用核验过官方哈希的 ES CLI，且只读查询。
- AI 模型、Conda、Python 环境、CUDA、Windows 系统目录等继续保护。

## 验证

- Python 回归测试全部通过；新增 v3.6 UI 结构和发行检查。
- Chromium 实际 HTML/JS 渲染：桌面 1600px、手机 390px，检查导航、舒适/紧凑切换、移动卡片勾选与详情、分级建议、多盘步骤栏。
- 浏览器截图全部使用模拟数据。真实 Windows C 盘删除与移动硬盘扫描尚未验收。
- 新版 ZIP 需单独进行 VirusTotal 检测，任何旧版扫描结论均不适用。
