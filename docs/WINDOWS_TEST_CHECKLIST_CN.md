# C-Scan Studio v3.4.0-beta.2：Windows 实机验收清单

本测试版在隔离环境完成了模拟回归测试、Windows/Linux GitHub CI 与浏览器模拟交互；**尚未在用户真实 C: 盘上执行删除验证**。

## 一、只读体验与安全边界（推荐先做）

1. 从独立来源校验 `C_Scan_Studio_v3.4.0-beta.2_Source.zip` 的 SHA-256，解压到非 C 盘（例如 `D:\CScan_Test`）。不要在 ZIP 内直接运行。
2. 双击根目录唯一的 `00_启动C-Scan智能清理与安全中心.bat`。查看界面是否只在 `127.0.0.1` 运行、是否没有管理员权限弹窗、是否显示零个预选清理项。
3. 点击“快速扫描”，记录 Windows 版本、Python 版本、扫描时间、识别目录及异常；**不要点击最后的 DELETE**。
4. 主动勾选一项绿色项目，点击“先预览”。逐页查看文件路径、大小、修改日期，并核对是否只包含自选的缓存类别。
5. 点击“取消，暂不清理”，确认没有文件被删除；再次进入预览应取得新的凭证。
6. 在 Everything 页面检查索引状态。如果未准备经 SHA-256 验证的官方 ES CLI，程序不得执行 PATH 中来路不明的 `es.exe`，应进行限时只读扫描。
7. 进入“在线安全验证”页面执行本地源码哈希核对；若计划公开发布，应分别给本版 ZIP 做 Windows Defender 和 VirusTotal 扫描，**不能套用 v3.3.1 的报告**。

## 二、真实删除验收（仅在备份完整、用户自愿的隔离测试账号/虚拟机中）

- 创建专门用于测试的临时目录和 **可重建的无敏感内容**，保持符合软件当前允许的真实 Windows Temp 目录/文件年龄规则。
- 先做磁盘和测试目录备份，查看清单和路径，确认所有候选是愿意永久删除的测试数据。
- 检查新预览页面中 50 条分页、不允许预览红色或灰色条目、120 秒到期需重新预览、输入错误确认码无法删除。
- 获得授权后才实际执行测试清理；同时运行无关进程写磁盘时，应看到 **净空间变化可能不同于已删除逻辑大小**。
- 验证文件数量、失败与跳过数、前后 C 盘可用空间和日志一致。完成后检查其他程序、Conda/venv/AI 模型仍可正常运行。

## 三、保留的验收证据

记录：Windows 版本与当前权限、C 盘空间前后读数、开始和结束时间、扫描类别与实际删除候选、相关日志、Everything / ES 官方版本及校验结果、无误报/误删的独立确认，以及 Microsoft Defender/第三方报告链接。共享日志前删除用户名与私人路径。

安全说明：源码自动测试与多引擎扫描**不构成绝对安全或无毒认证**。清理逻辑使用文件大小、mtime 和路径检查，无法绝对消除 Windows 文件系统中的所有并发竞争；正式生产大规模使用前，应由 Windows 专项测试验证。
