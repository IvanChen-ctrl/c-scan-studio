# C-Scan Studio v3.5 多磁盘重复文件 / 分类 — 简明操作手册

1. 从可信渠道下载该版本 ZIP，核对**与该 ZIP 一致的 SHA-256**；解压到独立文件夹。
2. 双击唯一的 `00_启动C-Scan智能清理与安全中心.bat`，在侧边栏点击 **「其他盘查重与分类」**。
3. 勾选需要读取的本地 D:～Z: 磁盘（可多选）；**默认没有勾选任何磁盘**。网络盘、C: 和任意输入路径都不可用于这个模块。
4. 选择最小重复文件大小：普通资料推荐 1 MiB；多媒体素材推荐 16 MiB。选择的是**查重门槛**，分类统计仍包含更小的文件。
5. 点击 **「开始只读分析」** 并确认。进度栏可停止。文件只有完整 SHA-256 相同才能算重复，速度受硬盘、USB 和大文件大小影响。
6. 查看“智能文件分类”各类型的数量和逻辑大小；点击 **「查看该类所有文件」** 可分页浏览完整路径、大小、日期与分类依据。
7. 展开重复组，先看**建议保留的候选原件**，再审阅其它副本。**绝不要依据名字相同、哈希相同就直接删除工程、模型、备份或被软件引用的文件。**
8. 右上角选择 JSON 或 CSV 导出本机完整报告。报告含真实文件路径，**不要直接上传公开 GitHub 或杀毒平台**。

## 风险说明

- **真正相同：** 大小与 SHA-256 相同代表校验当时的字节相同，不保证可安全移除其中任何一份。
- **扫描不完整：** 超限/取消/文件被修改/无法访问时，该次扫描不能证明整盘已经查完。
- **模型、源码和虚拟磁盘：** 默认红色保护、仅展示；不要在这个模块直接处理。
- **源文件与重复副本：** 软件仅提供人工建议；本模块从不执行删除、移动、隔离或重命名。
- **智能分类：** 这是可解释的扩展名、文件名规则，并非 AI 对文件内容的语义判断，可能存在误分类。
- **空间统计：** 理论可合并逻辑大小 != 真实磁盘可释放容量。硬链接不当作多份占用。

## Windows 测试建议

先准备一个空的 D: USB 测试盘（不含私人文件）：放两份内容完全相同的 MP4、一份同名但内容不同的 MP4、一些不同扩展名的文件。确认只出现真正相同的那组，并检查停止、重新扫描、分类文件翻页和导出报告。**不要在测试开始就清理真实生产文件**。
