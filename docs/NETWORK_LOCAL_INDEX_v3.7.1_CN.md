# C Scan Studio — 网络盘本地文件名索引（v3.7.1 候选）

## 为什么增加此模块

已有 `v3.3.1` 的 Everything/ES 模块主要搜索 C:；新版本 PR #14/#15 已支持 O: 等 Windows 映射网盘和无大小限制搜索，但 Everything 1.4 需人工在 `Tools > Options > Folders` 加入网络路径，且企业盘可能并未建立索引。

新增 `Network_Index.py` 在**不替换 Everything、不读取文件内容**的前提下建立独立 SQLite 元数据索引。用户已说明误传 HuzhuDesk ZIP；它仅提供少量数据持久化与失败恢复设计启发，**不是目标搜索引擎**。用户指定应重点参考的 **CoractiveFileFinder** 源码尚未提供，因此本候选版没有声称对其源码或算法完成比对、移植。

## 操作（Windows 10/11）

1. **普通用户会话**运行 C Scan Studio；确认 Windows 资源管理器能打开 `O:\`。管理员会话可能无法看到普通用户映射的盘符。
2. 进入“**大文件快速搜索**”，选择 `O:` 或 `P:`，选择本机**固定盘 D: 等**作为索引保存位置。索引将储存于 `D:\CScanStudio_NetworkIndex\O_<映射身份摘要>.sqlite3`。
3. 点击“**建立 / 续扫索引**”，阅读机密路径提示并手动确认。默认每次最多检查 12,000 个目录项或运行约 12 秒，结束后显示已记录文件、剩余待处理目录、是否完整。
4. 若提示“partial／尚不完整”，再次点击同一按钮继续。查询关键词 `Fab`、中文文件名、`.pdf` 或留空；所有大小的文件包括零字节文件均可索引。
5. 搜索优先使用经过 SHA-256 校验的 Everything ES；当其没有可显示结果时才读取用户选定本地磁盘已有的 SQLite 索引。不自动访问网盘进行增量同步，也不会据此触发清理。

## 使用范围与限制

- 仅支持当前 Windows 会话映射的 `D:...Z:` **DRIVE_REMOTE** 盘符；只读目录项的路径、名称、大小、修改时间，**不打开文件内容、不计算内容哈希、不删除网盘文件**。
- 索引库是**未加密的本地 SQLite 数据库**，路径和文件名可能属于内部信息；必须符合所属组织的数据存储政策。不要将其同步、发布到 GitHub 或与他人共享。
- 保存位置仅允许本地 D:～Z: **固定磁盘**，不写入 C:，拒绝链接/重解析的索引文件。软件不自动清空、迁移或覆盖历史数据库。
- 完整扫描完成前，旧文件条目会继续保留（可能已过时）。只有一次没有文件读取错误且完整结束的手动扫描才能移除失效条目；断线、失败、取消均标记 partial。
- 目录可能在扫描时变化，因此完整标记只说明该轮遍历结束，不代表实时一致；索引中展示的文件可能已被修改、移动或删除。单次网络 I/O 阻塞可能导致实际等待超过预算。
- 避免在超大企业共享盘上频繁全量索引。首次扫描需遵守网络管理员和共享盘使用规范。缓存不自动定期更新；必须手动再次点击。
- 如果是 UNC 路径索引、WebDAV、OneDrive 或某些不标准虚拟盘，可能无法识别为映射网络盘；不得绕过盘符/身份检查。

## 安全验证与真实测试

本项目测试只使用自有临时文件和模拟 Windows 映射盘，覆盖明确授权、无 C 盘数据库写入、索引断点续扫、零字节文件、中文/ASCII 文件名、文件符号链接拒绝、SQLite 链接拒绝、部分扫描保存、缓存优先级与取消保护。真实企业 O: 实机访问、服务器限流、Windows 映射身份、网络 I/O 阻塞仍需独立验收。
