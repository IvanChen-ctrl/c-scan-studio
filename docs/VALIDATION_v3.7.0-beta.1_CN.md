## 新增回归针对的实际风险

- 固定 Unity 缓存叶目录，环境变量与用户配置不能扩展删除权限。
- 离线保护由服务器强制执行；页面刷新、未提交设置、旧轮询和扫描提交并发时的显示与权限一致。
- Unity/Hub/Package Manager/Bee 运行或进程检测失败时拒绝清理；空或异常 tasklist 输出不再被解释为无进程。
- 精确旧日志名和年龄门槛，保留许可证与子目录；Unity工程落在 Temp 或被放入缓存目录时保护源内容。
- 文件被同大小、同修改时间的新文件替换后，旧快照仍因文件身份不符而拒绝删除。
- 读取失败、取消、超限、目录改变和链接跳过不假装完整；权限未知不显示为未找到。
- Windows DirEntry 零文件身份回归，硬链接/重叠路径去重及跨盘统计。
- 配置只输出cacheRoot，registry凭据不进入诊断报告。
- Windows便携包入口、资源路径、辅助脚本分发与禁止任意Python代码入口。
